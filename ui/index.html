Pas de clavier MIDI ? Utilise le clavier de l'ordinateur

Rangée du milieu = touches blanches, rangée du dessus = touches noires (positions physiques d'un clavier QWERTY). Z / X : octave − / +. C / V : vélocité − / +. Alt maintenu = pédale de sustain.
